Tossed Out - Web Development Project

This website was made for a school assignment using Flask and your usual web development languages; HTMl, CSS, Javascript. The idea behind it is, its a website that sells groceries - but since the assignment spec required the website to have a sustainability angle, it sells groceries that have physical imperfections but are still perfectly safe to eat.

By right this was supposed to be a group project, but I ended up doing basically everything in regards to the actual programming, so if I were to list down everything I did, we would be here all day. If I had to point out a few notable features, I'd bring up the PayNow QR Code generation for payment, the card game minigame which gave vouchers and discounts for users who won at the game, and the chatbot system using plain Javascript, without generative AI . Everything else in here is essentially your standard shopping website with a staff dashboard and all that nice stuff.

Before working on this project, I had no experience or knowledge in Flask, so about 3/4 of the time I spent doing this project was actually just time spent on figuring out Flask. And this was before ChatGPT was actually good at anything, so all I had was just pure reading the documentation and StackOverflow. Impressive right?

Turn Based Creature Battler Prototype Game

When I tell people that I have too much free time, this is what I mean. For some reason that even I am unsure of, I decided to attempt to learn the C programming language, completely unrelated to anything having to do with school or any of my classes. This "game" is the culmination of this attempt.

This game was supposed to be some kind of Turn Based RPG Game, like Pokemon, but I only ever got around to making the Turn Based Battling part. This game was written in C, using the SDL Library for graphics and pixel art drawn by me.

There are 4 moves a character can do, melee, projectile, block and move. Melee attacks move you closer to the enemy, and being closer to the enemy allows both you and the opponent to deal more damage. Projectile attacks give some sort of effect based on which creature uses it, and blocking just makes the creature receive less damage and heal a little bit of health.

As you can tell I put quite a bit of thought into trying to design some sort of simple but complex battle system, but obviously I'm not a game designer so its not very balanced or good.

I also tried to program some sort of AI for enemies, but I gave up halfway through and just made it spam projectile attacks.

Find Music - Personal Passion Project

As you will come to see with the next few projects, I like music. I really like music. Words cant describe how much I enjoy music, so I made a website instead.

Building upon my knowledge of Flask and Python from my school project, I made a website that takes in a list of genres, playlists or an album, and spits out an album recommendation based on that. To accomplish this, I used Web Scraping (BS4) to get data from a music review website I frequently peruse called AlbumOfTheYear.Org, as well as the Spotifty API for handling playlists and album links.

To my surprise, this worked really, really well. So well, in fact, some of the recommendations it gave me are albums that ended up as some of my most listened to albums this year. It was so beautiful, and it worked so well, and then AlbumOfTheYear.Org had to go and upgrade their CloudFlare subscription, and now my web scraping bot gets the boot anytime it tries to scrape. A true crying shame.

I tried and I tried, but you can't take down CloudFlare - only CloudFlare itself can do that. Instead of mourning, I'm going to share some of my favourite albums that this website recommended me - it's what the website would have wanted me to do.

Velonix - Business App Development Project (WIP)

This is a Music Streaming Platform I'm developing in ASP.Net Web Forms using C# for a school module. Currently I've made all the music playing functionality, as well as viewing and searching through albums, songs and artists.

The idea behind this is that most streaming platforms don't have any way to review or discuss music on the platform itself, usually users are forced to go to third-party websites to discuss, like AlbumOfTheYear.org. So what I'm trying to do is create a platform where users can discuss and listen to music all in one platform.

Since this is a Work-In-Progress project, the GitHub Repository is private, so don't try to click the button.
